# Manifest of Pure elements to materialise as Java bindings via
# `legend java-bindings --bindings-file`. Each non-blank, non-comment
# line is a Pure FQN. The CLI resolves it to an element in the platform
# model and dispatches it by kind:
#
#   Function     → static-method wrapper on the generated facade class
#   Class        → Java interface (with property closure walked)
#   Association  → both endpoint classes seeded; injected properties
#                  surface on each side's interface
#
# Used by the `exec-maven-plugin` configuration in this module's
# pom.xml during the `generate-sources` phase. Edit and rebuild to
# extend the bound surface; do not check in the generated Java itself
# (it lives under `target/generated-sources/`).
